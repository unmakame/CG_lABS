# CG_lABS



## Запуск на macOS

Установить Vulkan SDK 1.4.321.0 в ~/VulkanSDK/1.4.321.0, CMake и инструменты C++.
Из корня репозитория выполнить `zsh run.sh 1` (номер работы: 1, 2 или 3).
Скрипт собирает приложение перед запуском. Инструкции находятся в README каждой работы.

Библиотеки в third_party включены для сборки без скачивания зависимостей.
Vulkan helper Dear ImGui дополнен буфером глубины. Лицензии библиотек сохранены.
