## Соответствие заданию на оценку 5

- **База: текстуры из файлов.** stb_image загружает PPM; UV генерируются вместе со сферой. Полноценное освещение из Lab 2 сохранено.
- **Динамический UBO.** Единый modelBuffer_, stride выровнен по minUniformBufferOffsetAlignment; offset передаётся в vkCmdBindDescriptorSets.
- **GPU-память.** Вершины, индексы и текстуры в DEVICE_LOCAL памяти, копируются через staging.
- **1. Несколько материалов.** Sphere → Albedo texture: Earthlike / Marble. Два набора дескрипторов материалов используются всеми моделями.
- **2. Нетривиальное сэмплирование.** Animated sampling for this model; Enable sampling effects; Play texture animation. По умолчанию эффект включён для первой сферы. Время и флаг передаются push constants; шейдер выполняет две выборки с разными UV и модуляцию цвета.
- **3. Specular / emissive.** Earthlike использует карты блеска и свечения (Perlin). Marble использует чёрную заглушку 1×1 для обеих отсутствующих карт. Emissive прибавляется после Blinn–Phong.

`src/main.cpp` — окно и жизненный цикл Vulkan. `src/scene_renderer.hpp` — ресурсы, дескрипторы, камера, UI и команды отрисовки. `src/sphere_mesh.hpp` — геометрия. `shaders/` — GLSL. ## Управление и проверка

- Selected sphere: выбор сферы для перетаскивания. ЛКМ по области сцены с перемещением мыши двигает выбранную сферу в плоскости экрана.
- ПКМ по сцене: поворот камеры. Колесо: движение вперёд/назад. WASD: движение камеры, Q/E: вниз/вверх. Shift ускоряет движение; Focus selected наводит камеру на выбранную сферу. Поля интерфейса сохраняют возможность точного ввода.
- Space или Play animation: общая пауза. Animate this sphere: отдельная пауза выбранной модели без возврата к началу. Reset animation: явный сброс фазы всех моделей. Скорость задаётся в рад/с, dt отображается в секундах.
- Show surface normals (green): зелёные отрезки от вершин поверхности. Это диагностическая визуализация передней стороны; отрезки не проходят depth test относительно других объектов.
- В Lab 2/3 Show spotlight cones (white) управляет белыми линиями конуса отдельно от цветных маркеров света. Cone display length меняет только длину визуализации.

При сворачивании окна время отсчёта сбрасывается: восстановление не вызывает скачка на время простоя. Во время обычной работы dt не обрезается. Для проверки с Vulkan validation: `CG_BUILD_TYPE=Debug zsh run.sh` из папки работы (нужны установленные validation layers).

Математические проверки находятся в `../tests/math_checks.cpp`: FPS 10/20/30/60/144, пауза, смена скорости, некорректное dt и нормали после неравномерного масштаба. Проверка работающего GUI на GPU остаётся отдельным этапом; успешная сборка её не заменяет.
