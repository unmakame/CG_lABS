## Соответствие заданию на оценку 5

- **База: камера и направленный свет.** Camera position, yaw/pitch, FOV; Directional light, Direction, Light color, intensity, Ambient.
- **Материал и нормали.** Sphere → Tint, Specular color, Shininess. Нормали радиальные, при преобразованиях применяется inverse-transpose.
- **1. Дескрипторы сцены и модели.** Set 0: scene UBO и два SSBO. Set 1: трансформация и материал модели.
- **2. Точечные источники.** Point lights (SSBO): добавление/удаление, позиция, цвет, интенсивность. Blinn–Phong и затухание 1/r².
- **3. Прожекторы.** Spot lights (SSBO): дополнительно направление и внутренний/внешний угол. Мягкие края; равные углы дают резкую границу.
- **4. Визуализация света.** Show light markers: неосвещаемые сферы цвета источника; для прожектора направление и каркас конуса. Линии конуса являются экранной диагностической визуализацией.

## Код и проверка

`src/main.cpp` — окно и жизненный цикл Vulkan. `src/scene_renderer.hpp` — ресурсы, дескрипторы, камера, UI и команды отрисовки. `src/sphere_mesh.hpp` — геометрия. `shaders/` — GLSL. Общий Vulkan helper в `../third_party/imgui/backends` дополнен буфером глубины; папку third_party необходимо сохранять.

Проверки: C++/GLSL сборка, spirv-val и CPU-проверка геометрии. Визуальная проверка всех действий и Vulkan validation на доступном GPU ещё не завершены; оценка преподавателя не гарантируется. Максимум 8 сфер и по 32 источника каждого типа в интерфейсе; shader SSBO arrays имеют runtime length.
